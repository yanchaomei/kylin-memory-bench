# 两款真实智能体的完整增量任务评测

结果运行日期：2026-10-09。收回与重算日期：2026-10-16。版本：0.2.0。

## 1. 实验回答什么

这轮实验检验评测工具能否区分三个问题：资料有没有帮助完成后续任务；智能体是否同时遵守保留边界；同一任务重跑时，整个执行链是否持续成功。结果来自 OpenClaw 和 Hermes 的原生运行，不是评分替身。

评测器为每条案例建立独立工作区，每个阶段开启新进程与新会话。当前消息不携带评分真值，事实需通过框架自己的长期记忆保留。实际文件、长期记录、工具轨迹和模型回复共同参与核对，不能用一句「已完成」代替行动。

## 4. 重复可靠性

`pass^k` 表示从已分配重复中抽取 k 次，要求每次都成功的估计；三轮时 `pass^3` 就是三轮全部成功的案例比例。它与「多试几次至少成功一次」不同。

| 指标 | Hermes | OpenClaw |
|---|---:|---:|
| pass^1 | 90.28% | 82.64% |
| pass^2 | 89.58% | 76.39% |
| pass^3 | 43/48，89.58% | 34/48，70.83% |
| 重复状态一致率 | 97.92% | 81.25% |
| 两臂均在三轮成功的独立任务 | 19/24，79.17% | 11/24，45.83% |

按 24 个匹配任务计算，8 个任务仅 Hermes 获得全轮成功，没有仅 OpenClaw 成功的任务；精确双侧 McNemar 检验 p=0.0078125。该端点包含模型、CLI、工具及证据链的运行可靠性。

同时检查两端证据均完整的 16/24 个任务，只有 1 个单侧成功差异，p=1。两组结果共同说明：本轮能稳定识别系统级可靠性差异，而完整证据子集尚不足以支持固有记忆算法的优劣判断。报告把这两层结果分别保留。

## 6. 三个可追踪的发现

### 6.1 没有保存禁止项，也可能错误复用合法项

两款框架各有 4 个 provided 边界案例，在三轮中都将合法对照项目的值回答给未知项目，因此共 12 次明确失败。声明的长期记忆快照没有命中禁止标记；合法对照查询也返回相同合法值。

例如 `episode-d4160e87440819c4`：未知项目查询和合法项目查询都得到 `/srv/projects/2340999c1f7d321d`。这是错误关联和未正确拒答，不是观察到禁止标记泄漏。四路证据让这两类问题能够分开解释。

### 6.2 有保留记录，不代表每次都能调用

OpenClaw 第二轮的 `episode-2a4277ef329ebafa` 未能回答相近项目的合法字段，`similar_subject` 断言记录为 `omission`。该合法值在写入、四次干扰和两个查询后的长期记忆快照中均可见，因此能把「记录仍在但未正确调用」与「资料根本没有保存」分开。这类遗漏与拒绝保留禁止信息是不同问题，不通过「全部回答未知」获得边界高分。

### 6.3 前一步成功，不等于整条任务链成功

OpenClaw 第三轮的 `episode-decd9c6783530213` 正确生成了 `checkpoint.json`，但最终没有生成 `handover.json`。第一步的产物与字段均通过，第二步判为 `incorrect_reuse`。前半段成功不会冲抵最终行动缺失。
