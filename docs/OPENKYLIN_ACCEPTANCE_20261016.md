# openKylin 目标系统验收报告

日期：2026-10-16。工具版本：0.2.0。

## 1. 验收结论

Kylin Memory Bench 已在 openKylin 2.0 SP2 完成工程回归、用户级安装、Debian 包解包运行、已知行为校准，以及 OpenClaw、Hermes 两款真实智能体的增量任务评测。两款框架各执行 12 条案例、88 个阶段，合计 176 个阶段全部正常完成；原始运行目录、报告与证据清单均已核验。

评测发现两款框架都能在新会话中保留、调用、更新信息并生成正确文件，同时都在一个未知项目查询中串用了合法项目的值。工具将它判为边界失败，保留了可追踪的原因和原文，不以运行成功代替能力成功。

两款框架都获得 6/6 完整配对。在这些配对中，提供资料时的主目标达成率为 100%，扣除资料时为 0%，资料收益为 +100 个百分点。Bootstrap 以 6 个独立配对重采样，当前样本的区间为 [100,100] 个百分点；规模与覆盖同时公布。

两端都实际生成了修订前的 `checkpoint.json` 和修订后的 `handover.json`；最终文件使用反馈的新交接码。无资料控制臂没有生成无依据文件。路径、内容、新鲜度和文件摘要均从实际产物核对，不依据完成声明打分。
