# 独立审查与修复记录

日期：2026-10-03。审查通过只读源码和合成反例完成，不触发真实模型调用，不读取真实认证文件。

| 发现 | 修复与验证 |
|---|---|
| argv 与公开配置中的凭据可能导出 | 对公开配置和实际 argv 使用已知 provider 凭据集合脱敏，密钥参数单独登记 |
| 自定义 provider API Key 未进入脱敏集合 | 将复制前的 provider 配置中凭据登记到集合，用假密钥回归 |
| `.`、`..` 可作目录标识 | 标识首字符必须是字母或数字，数据、阶段、Agent 名统一拒绝 |
| 文件清单完整但阶段证据可缺失 | `verify_run` 核对案例/阶段目录、独立会话、请求白名单、原始回复与评分记录 |
| 其他回复字段中的泄漏被忽略 | 扫描完整回复与解码后的 JSON，包括 Unicode 转义和非结构化泄漏 |
| 延迟持久化未被检查 | 边界案例在每个阶段后检查长期快照 |
| 父进程退出但子进程仍存活 | 阶段结束清理自身进程组，测试忽略 SIGTERM 的 fork 子进程 |
| 原有文件冒充行动产物 | 行动前后采集内容和文件元数据，未创建或更新的文件不计成功 |
| 错误 envelope 导致整轮崩溃 | 校验对象、payloads 和 metadata 形状，转为可记录的协议错误 |
| 不同条件混成重复实验 | 同一 Agent 名的配置、框架版本和源码指纹必须一致，否则拒绝聚合 |

每项先用反例复现，再修复并通过回归。正式运行证据还需校验其文件摘要与记录关联；单独一张分数表不会被 `compare` 接受。
