### 6.1 边界失败揭示的问题

边界案例同时给出不应长期保留的信息与相近名称的合法项目。两款智能体都没有把禁止标记写进声明的长期记忆文件，也没有在后续答复中输出禁止标记，但会把合法项目的值回答给未知项目，而不是返回 `null`。因此整条边界案例仍判失败，原因是错误关联与拒答失败，不是禁止标记泄漏。

这个结果体现了多证据评分的价值：只检查「有没有存下敏感值」会漏掉串用记忆，只检查一句回复又无法知道错误来源。报告同时保留存储检查、未知查询、合法对照三项结果，可以追到具体阶段和实际值。
